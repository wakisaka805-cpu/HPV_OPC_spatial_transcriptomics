# Data and input-file map

This repository contains analysis code and gene-set definitions, but does not redistribute the complete public source datasets or non-public study-derived GeoMx data.

## Default directory layout

```text
data/
├── TCGA/
│   ├── input/
│   │   ├── clinical.rds
│   │   └── expression_gene_symbol.rds
│   └── TCGA_HNSC_RNAseq_HPV_status_Nulton2017.rds
├── GeoMx/
│   ├── GeoMx_ssGSEA_ROI_level_scores.csv
│   ├── GeoMx_ssGSEA_case_level_scores.csv
│   ├── GeoMx_LFR_Q3.rds
│   └── GeoMx_ROI_annotation.csv
└── PTT/
    ├── PTT_expression_gene_symbol.rds
    ├── PTT_ssGSEA_scores_HPV.csv
    └── PTT_ssGSEA_scores_HPV_v2_TexLike.csv   # generated by script 08
```

## TCGA-HNSC / OPSCC

TCGA-HNSC is a public third-party dataset. `R/01_TCGA_OPSCC_primary_marker_survival.R` expects the processed gene-symbol expression matrix and clinical data shown above, plus the HPV annotation object used in the analysis. The strict OPSCC cohort is constructed in code and contains 77 RNA-seq cases after the manuscript filters.

The exact eight-gene-set archive used by the workflow is distributed under `gene_sets/TCGA_tonsil40_gene_sets_8.rds` because it contains gene-set definitions rather than participant-level data.

## GeoMx

The GeoMx scripts require the four study-derived inputs listed above. These are intentionally excluded from the GitHub code archive. Their availability must follow the final manuscript Data Availability Statement and institutional/ethics requirements.

## PTT / GSE228432

The PTT analysis is based on public GEO series GSE228432. Supply the processed gene-symbol expression matrix as `PTT_expression_gene_symbol.rds` and the existing sample annotation contained in `PTT_ssGSEA_scores_HPV.csv`. Then run:

```r
source("R/08_PTT_ssGSEA_rebuild.R")
```

This creates `PTT_ssGSEA_scores_HPV_v2_TexLike.csv`, which is consumed by Figure 5 scripts. The release code harmonizes the historical internal Tex-like label to `TEX_LIKE_PROGRAM_SHI2023`.

## Environment-variable overrides

Default locations can be overridden with:

- `TCGA_ROOT`
- `GEOMX_ROOT`
- `PTT_ROOT`
- `RESULTS_ROOT`
- `HPV_OPC_REPO_ROOT`

See `R/config.R`.
