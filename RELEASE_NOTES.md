# Release v1.0.0

Validated public code release prepared for the revised PLOS ONE manuscript.

Key release changes:

- standardized GeoMx/SpatialDecon outputs under `results/GeoMx/`;
- removed dependence on manually created root-level Figure 4 inputs;
- standardized manuscript figures under `results/PLOS_ONE_Revision_Figures/`;
- replaced the obsolete PTT CSV-matrix assumption with the validated `PTT_expression_gene_symbol.rds` workflow;
- included the exact archived eight-gene-set definition object required for full Hallmark membership;
- harmonized the historical Tex-like internal label with `TEX_LIKE_PROGRAM_SHI2023`;
- excluded local/private data, generated patient-level outputs, RStudio state, and superseded code;
- updated `CITATION.cff` to version `1.0.0`;
- included the validated `sessionInfo.txt`.

The Zenodo DOI is intentionally not included in this pre-archive package and should be added after Zenodo creates the archived release.
