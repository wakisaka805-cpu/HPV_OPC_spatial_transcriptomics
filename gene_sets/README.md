# Gene sets

This directory contains the Supporting Information workbook and the exact archived eight-gene-set R object used by the computational workflow.

- `S1_Table_gene_sets.xlsx` — Supporting Information workbook describing the prespecified programs.
- `TCGA_tonsil40_gene_sets_8.rds` — exact archived eight-gene-set definitions used for ssGSEA; included because the S1 workbook does not itself contain the full Hallmark membership lists.
- `gene_set_sources.csv` — source/provenance notes.

The release code harmonizes the historical internal Tex-like label `TEX_LIKE_CORE18_SHI2023` to the manuscript label `TEX_LIKE_PROGRAM_SHI2023` without changing the underlying genes or scores.
